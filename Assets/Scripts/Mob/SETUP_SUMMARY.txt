================================================================================
                      🎮 QUICK START (5 MINUTES)
================================================================================

STEP 1: BAKE NAVMESH
   → Window > AI > Navigation
   → Select floor > Check "Navigation Static"
   → Bake tab > Click "Bake"

STEP 2: CREATE MOB PREFAB
   → GameObject > 3D Object > Capsule
   → Add: NavMeshAgent, MobAI, MobHealth, Rigidbody
   → Configure
   → Drag to Assets/Prefabs folder

STEP 3: CREATE SPAWNER
   → GameObject > Create Empty (position where mob spawns)
   → Add: MobSpawner component
   → Assign: Mob Prefab
   → Set: Spawn Type (Ceiling/Floor/Wall/Object)
   → Set: Trigger Type = "Player Proximity"
   → Set: Trigger Distance = 5

STEP 4: TAG PLAYER
   → Select player GameObject
   → Inspector > Tag > "Player"

STEP 5: TEST
   → Press Play
   → Walk near spawner
   → Mob spawns and chases you! 🎉

================================================================================
                      🎮 TRIGGER TYPE GUIDE
================================================================================

PLAYER PROXIMITY (Recommended for horror)
   → Spawns when player gets close
   → Use: Jump scares, ambushes
   → Trigger Distance: 2-5 for sudden, 8-15 for anticipated

TIMED
   → Spawns after set time
   → Use: Pressure/time limits, scripted events
   → Spawn Delay: Set when mob should appear

MANUAL
   → Call TriggerSpawn() from code
   → Use: Cutscenes, boss fights, story triggers
   → Perfect control over timing

================================================================================
                      🐛 TROUBLESHOOTING
================================================================================

❌ "Mob doesn't move!"
   ✓ NavMesh baked? (blue overlay visible?)
   ✓ Mob on NavMesh surface?
   ✓ NavMeshAgent enabled?

❌ "Mob doesn't spawn!"
   ✓ Mob Prefab assigned to spawner?
   ✓ Player has "Player" tag?
   ✓ Within trigger distance?
   ✓ Check console for errors

❌ "No sounds!"
   ✓ AudioManager in scene?
   ✓ Sound names match exactly?
   ✓ Sounds added to AudioManager array?
   ✓ Note: Mobs work without sounds!

❌ "Player doesn't take damage!"
   ✓ PlayerHealth component on player?
   ✓ Player has "Player" tag?
   ✓ Mob in attack range?

================================================================================
                        💡 HORROR GAME TIPS
================================================================================

SOUND = 50% OF THE SCARE
   → Use pre-spawn sounds for tension
   → Vary pitch for uniqueness
   → Ambient breathing/growling

LIGHTING MATTERS
   → Dark areas = more scary
   → Flickering before spawn
   → Red lighting for danger zones

PACING
   → Don't spam mobs
   → Mix proximity and timed
   → Build tension, release with spawn

SPAWN LOCATIONS
   → Ceiling above doorways = jump scare
   → Long hallways = build dread
   → Behind doors = pure horror
